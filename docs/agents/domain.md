# Domain Docs

Before exploring, read the root [context map](../../CONTEXT-MAP.md), follow the
relevant context link, and read ADRs under `docs/adr/` that affect the current
area. Proceed silently when an applicable ADR does not exist.

This repository uses the multi-context layout: root `CONTEXT-MAP.md`, domain
documents under `docs/domain/`, and repository-wide ADRs under `docs/adr/`.
The domain set is recorded in [ADR 0001](../adr/0001-certificate-automation-domain-set.md).
Use glossary terms consistently and surface conflicts with existing ADRs.
