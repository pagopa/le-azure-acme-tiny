# AGENTS.md

## graphify

Use Graphify first for questions about this repository's architecture,
structure, file relationships, or how to add, modify, or find code.

- If `graphify-out/graph.json` exists, run `graphify query "<question>"`.
- Use `graphify path "<A>" "<B>"` for relationship questions.
- Use `graphify explain "<concept>"` for focused concept questions.
- Use `graphify-out/wiki/index.md` for broad navigation when present.
- Type `/graphify` in Copilot Chat to build or update the graph.
